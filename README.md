# 带娃一日游攻略（技能）

这是一份给 AI 助手用的写作技能，告诉它怎么为带小孩的家庭排一天的行程，写成手机 3 分钟读完的攻略。

## 它解决什么

- 第一屏是大标题、导语和「今天谁去」，接着是天气卡和带车程的时间轴；出发前要打的电话单独一张卡，最多 3 件
- 正文只有最新一版，改动记录不放页面，记在 `来源.md`
- 查资料的过程放内部记录，正文只写查实的结果，来源链接放在店卡最后一行，最多 3 个
- 查不到的写成「查不到 X，原因是 Y」，只记在 `来源.md`，页面上不放这句；要问店家的事放进「出门前打个电话」卡
- 每个版块有条数和字数上限，全文汉字 ≤1500

## 怎么用

1. 把 `SKILL.md` 放进你的助手技能目录。
2. 对助手说：「用带娃一日游技能，帮我排 X 月 X 日去某地的一天。」
3. 它会先问出发地、孩子年龄和午睡时间、每位家人的口味、想去的店，再查资料、排路线。
4. 你会拿到一份单文件 HTML，用 v4 合并版式，这就是交付物；md 只是说明文件，截图只用来验收，都不能代替 HTML。
5. 想改就直接说，它会覆盖正文，在 `来源.md` 加一行改动记录，页面上不放。

## 里面有什么

- 先定死的写法 15 条
- 路线怎么排，围着午睡和饭点，从出发地往一个方向推进，需要回头就单独写一行，写多开多少公里、换来什么，路程加时
- 每家店的固定写法，每张卡分四段，依次是结论、事实（带查证日期）、下一步、依据，每行一句话，人物用【大人 1】【大人 2】【孩子】填写位标签，没有内容的行省略
- 手机网页只有一种版式：v4 合并版式，以昆山样稿 v4.3 为准（见 SKILL.md 第 9 节），每次交付一份单文件 HTML：首屏、天气卡、时间轴、打电话卡、店卡、万一有变、出门清单、收尾一句；人物标签用【大人 1】【大人 2】【孩子】，只用 11 种颜色，不用脚本和外链；配图只用 CC0、公有领域或 CC BY 署名的示意图，base64 内嵌
- 用之前先填：家里几个人、每人的称呼和口味、孩子月龄、随身药品、出发地。这些只存在你自己那里，不进公开仓库，页面上一律用【填写位】显示（见 SKILL.md「用之前先填」一节）
- 交付前自查 15 条，自查结果不写进正文

`sample/昆山一日_样稿.html` 是一份昆山一日游的样稿，店名和地址都是公开信息，家人信息已去掉。

本仓库包含这些文件：`SKILL.md`、`README.md`、`LICENSE`、`来源.md`、`sample/昆山一日_样稿.html`、`sample/昆山一日_手机截图_375.png`、`tools/出游攻略检查.py`、`tools/隐私词表.示例.txt`。

检查程序的用法：`python3 tools/出游攻略检查.py sample/昆山一日_样稿.html`。它只读文件、不联网，逐条给出「通过」「不通过」「需人看」。想查页面里有没有漏出自家人名、地名或药名，把 `tools/隐私词表.示例.txt` 复制成同目录的 `隐私词表.txt`，一行写一个词，换成你自己的真实词；这个文件只留在本机，不要提交。没有 `隐私词表.txt` 时，这一项显示「需人看」。

技能只写攻略，不订位、不下单、不付款。
